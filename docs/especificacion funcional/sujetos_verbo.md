"El Tren de las Acciones" (Sujeto + Verbo)
Una vez que los artículos están firmes, introducimos los verbos. Para que enganche rápido y no se frustre, vamos a usar acciones que le resulten súper cotidianas, inmersivas y divertidas, como pintar o bailar.

La Dinámica: Armar una oración simple de tres partes.

La Pantalla: Tres cajones vacíos: [   ]  [       ]  [       ].

Las Opciones: Abajo le damos las piezas desordenadas: [ BAILA ] [ EL ] [ CONEJO ].

El Gancho Visual (Recompensa): Cuando logra ordenar "EL CONEJO BAILA", los botones se fusionan en una sola oración. La animación de recompensa es el mismísimo conejo haciendo algún pasito de baile de moda que a ella le divierta. Si armamos la oración "LA PRINCESA PINTA", la recompensa puede ser una transición mágica directa al ColoringGame que ya tenés programado en la app.
